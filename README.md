# ElectroShop TypeScript Practical Task

A small electronics store page built as a TypeScript practical assignment.

## Project files

- `index.ts` contains the TypeScript source.
- `index.js` is the JavaScript loaded by the HTML page.
- `index.html` and `Task1.html` display the ElectroShop page and its product loader.
- [`ElectroShop_TypeScript_Practical_Task.docx`](ElectroShop_TypeScript_Practical_Task.docx) contains the original task requirements.

## Run

Open `index.html` in a browser and select **Load Products**.
